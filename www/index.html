        Privacy policy
        

          
Last updated October 27, 2026

          
LumenCalc does not collect your data. There are no accounts, ads, analytics or trackers, and the app does not send anything about you to us or anyone else.

          
Everything stays on your device

          
Calculations, conversions and the code you run are processed on your device. The app makes no network requests of its own and works offline.

          
What is stored on your device

          
    
            
  • Your calculator history, variables and a few preferences (like degrees or radians), kept in the app's local storage. Clear the app's data in your device settings to erase them.
    • 
            
  • A draft of the code in the editor.
    • 
            
  • Files you choose to save, which go only to the LumenCalc folder you set under Save folder.
    • 
          

          
Permissions

          
On Android, LumenCalc asks for storage access only so it can save and open your code files in the LumenCalc folder. It does not read other files.

          
Code you write

          
Code in the Code tab runs in a sandbox inside the app. If your own code makes a network request, that request is yours; LumenCalc does not add or monitor it.

          
Changes

          
If this policy changes, the new version will ship with an updated version number and date.
